title: Panel copies
description: Copies of this panel on other servers, each a full, normal install
  of the fork’s latest release with this panel’s full backup restored onto it,
  started on standby (see GET /panel/api/server/standby) so it can take over
  when this panel is lost. When this panel is newer than that release, or the
  same release with a different binary, its own binary is copied over the
  installed one. Copying never changes this panel. The SSH password is used once
  to install a key of the panel’s own, kept with the relay keys, and is never
  stored. Super admin only. All endpoints under /panel/api/clones.
